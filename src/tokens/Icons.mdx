# Icons

The library ships the 50 most commonly used icons from [Tabler Icons](https://tabler.io/icons),
registered under stable, kebab-case names in `src/components/icons/icons.ts`.

Components that accept an icon — such as `Button` — take one of these names as a
prop (for example `iconLeft="search"`) instead of a component import, so
consumers never need to depend on `@tabler/icons-react` directly.

Use the standalone `<Icon name="..." />` component to render an icon anywhere else.

```tsx
import { Icon } from "e-ink-ui-lib";

<Icon name="search" size={20} />
```
