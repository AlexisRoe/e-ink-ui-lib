# Colors

Color tokens are defined on `:root` in `src/components/theme/theme.css`.
Every color anywhere in the tree is forced to greyscale by the theme
(`#root { filter: grayscale(100%); }`), so the palette itself is grey-based
even where hex values imply color.

## Core

<div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fill, minmax(200px, 1fr))", gap: 16, marginTop: 16 }}>
  {[
    { name: "--eink-color-primary", hex: "#000000" },
    { name: "--eink-color-secondary", hex: "#ffffff" },
    { name: "--eink-color-background", hex: "#ffffff" },
  ].map((token) => (
    <div key={token.name} style={{ border: "1px solid #ccc" }}>
      <div style={{ height: 64, background: token.hex, border: "1px solid #ccc" }} />
      <div style={{ padding: 8 }}>
        <code>{token.name}</code>
        <div style={{ fontSize: 12, color: "#666" }}>{token.hex}</div>
      </div>
    </div>
  ))}
</div>
