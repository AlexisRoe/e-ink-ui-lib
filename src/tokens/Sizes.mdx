# Sizes

Spacing, sizing, and border tokens follow a fixed scale, defined on `:root`
in `src/components/theme/theme.css`. Use these instead of hardcoded pixel
values wherever possible.

    </div>
  ))}
</div>

## Composite border tokens

`--eink-border-thin`, `--eink-border-medium`, and `--eink-border-thick`
combine a width, `--eink-border-style` (`solid`), and `--eink-border-color`
(`var(--eink-color-primary)`) into a single shorthand, e.g.
`border: var(--eink-border-thin);`.
